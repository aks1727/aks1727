## 👨‍💻 About Me

I'm **Akshat Kumar Sinha**, A working professional @Cogniant  and a B.Tech Computer Science & Engineering graduate focused on software development, test automation and problem solving.

I work across both **building software** and **engineering its quality** — from web and mobile applications to automation frameworks, APIs and algorithmic problem solving.

### What I do

- 🌐 **Full-Stack Engineering** — React, Next.js, Node.js, Express and databases
- 📱 **Mobile Development** — React Native and cross-platform applications
- 🤖 **SDET / QA Automation** — Selenium WebDriver,Playwright, TestNG, Cucumber BDD, POM and data-driven testing
- 🧠 **Problem Solving** — C, C++, Java, DSA and competitive programming
- 🎮 **Game Development** — Unity, game mechanics and physics *(Beginner)*
- ⚙️ **Engineering & DevOps** — Docker, Jenkins, GitLab CI/CD, Git/GitHub, Linux and Postman

> **I like understanding how things work, not just making them work.**
